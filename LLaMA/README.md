# LLaMA

LLaMA는 Meta에서 개발한 대규모 언어모델 시리즈이다.

## 발표 내용

- Scaling Law
- Data Curation
- Training Recipe
- Long Context Training
- GQA (Grouped Query Attention)
- 4D Parallelism
- Large-scale Distributed Training

## 핵심 내용

- 15T 규모의 토큰 사용
- Dense Transformer 구조 유지
- 최대 128K context 지원
- 데이터 품질과 스케일링 전략 중심 학습
